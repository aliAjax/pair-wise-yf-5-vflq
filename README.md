# 社区药房 · 冷藏疫苗箱借还管理

## 运行

```bash
npm start          # 或 node server.js
# 打开 http://localhost:3000
```

零依赖（Node 20+ 内置模块），数据持久化在 `data.json`（首次启动自动初始化，删除即重置）。

## 业务流程

1. **提交**：护士提交借箱单（姓名、需求容量、备注）。
2. **确认发放 / 改派**：调度员为待确认单选箱确认。只有「空闲 + 容量足够 + 消毒在有效期内」的箱可选；检查与占用在同一同步块内完成，多单争同一箱时先确认者占整箱，后确认者收到 409 与最新可用箱列表，改派其他箱后再次确认——同一箱不会被重复发出。
3. **归还**：登记封条（完好/破损）、温度、重量。温度超出 2–8°C 或封条破损 → 箱进**异常区**；否则进**待复核**。两种状态都不可再借。
4. **复核**：填写复核人与结论（必填留痕）。**放行** → 箱恢复可用、原借单结束；**继续隔离** → 留在异常区，可再次复核。未经复核放行的箱不会出现在可发放列表中。
5. **再次借出**：放行后的箱重新进入可用池，新借箱单可正常借出。

## 留痕

- 每张借单保留四个交接时间：提交 → 发放 → 归还 → 复核放行（结束）。
- 归还记录（封条/温度/重量/异常原因）与每次复核结论（含隔离结论）永久保留。
- 页面底部「交接时间流水」记录全部操作事件。

## 主要接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/state` | 全量状态 |
| POST | `/api/orders` | 提交借箱单 |
| POST | `/api/orders/:id/confirm` | 确认发放（冲突返回 409 + 可用箱列表） |
| POST | `/api/orders/:id/return` | 归还登记 |
| POST | `/api/boxes/:id/review` | 复核（`decision`: `release` / `hold`） |
